# T'au Cadre Sheets

Offline stat-sheet app for my T'au list. Open https://mishkashmoodle.github.io/tau-list-html/tau-list-html/ (thanks apple) in Safari or your web browser, then Share → Add to Home Screen (for adding it to your iPhone).

To update: replace `index.html`, then bump `VERSION` in `sw.js` (e.g. v1 → v2) so phones fetch the new copy.
